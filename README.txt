UNHL Website — First Working Version
====================================
Files: index.html, styles.css, app.js, data.js, logo.jpg

TO VIEW:
Unzip the package and open index.html in a modern web browser.
For reliable use across browsers, you can also run a local web server in this folder:
  python -m http.server 8000
Then visit http://localhost:8000

FEATURES:
- Home with 2026 and career leaders
- Season and career player statistics (2022–2026)
- Sortable tables, search, player profiles
- Historical records, awards, news, and special recognitions
- Responsive desktop/mobile design and official supplied UNHL crest

DATA NOTES:
- Data originates in the user's uploaded workbook.
- Career totals are preserved as provided rather than reconstructed.
- Name variants may need manual matching across seasons.
- Team standings, full game schedules and detailed box scores are not yet implemented.
- The website is static. Uploading a new workbook will not automatically refresh it.

PRIVACY IMPORTANT:
This ZIP is NOT password protected or access controlled. It contains league names and statistics.
Do not publish it to an unrestricted public web host if league-member-only access is required.
Use a host with authentication/access control for private distribution.
